## 第一节 权限机制

- 权限分级
- 声明权限
- 权限最小化原则

---

### 权限分级

| 级别 | 说明 | 授权方式 |
| --- | --- | --- |
| **普通权限** | 风险低（网络、震动、蓝牙查询） | 安装即授予 |
| **危险权限** | 涉及隐私（相机、定位、通讯录） | **运行时**由用户授权 |
| **特殊权限** | 影响系统（悬浮窗、安装未知应用） | 跳转系统设置页授权 |
| **签名权限** | 同签名应用之间 | 自动授予 |

```xml
<uses-permission android:name="android.permission.INTERNET" />        <!-- 普通 -->
<uses-permission android:name="android.permission.CAMERA" />          <!-- 危险 -->
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
```

---

### 常用危险权限组

| 权限组 | 权限 |
| --- | --- |
| 相机 | `CAMERA` |
| 位置 | `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION` |
| 麦克风 | `RECORD_AUDIO` |
| 通知 | `POST_NOTIFICATIONS`（Android 13+） |
| 媒体 | `READ_MEDIA_IMAGES` / `READ_MEDIA_VIDEO`（Android 13+） |
| 通讯录 | `READ_CONTACTS` / `WRITE_CONTACTS` |

> Android 13 起，读取图片视频从 `READ_EXTERNAL_STORAGE` 拆分为按类型的媒体权限。

---

### 权限最小化原则

```kotlin
// ✗ 为了拍一张头像申请全部存储权限
// ✓ 用系统相机 Intent 或 Photo Picker，完全不需要权限
```

设计建议：

1. 优先用**不需要权限**的系统组件（Photo Picker、系统相机 Intent、SAF）
2. 权限**按需申请**：用到功能时才申请，不要一进应用就弹一堆
3. 申请前先说明**为什么需要**
4. 用户拒绝后，功能**降级**而不是不能用

## 第二节 运行时权限申请

- 申请流程
- Activity Result API
- 被永久拒绝的处理

---

### 申请流程

```text
检查是否已授权
    ├─ 已授权 → 直接执行功能
    └─ 未授权
         ├─ 应该显示说明（用户曾拒绝一次）→ 弹自定义说明对话框 → 再申请
         └─ 直接申请 → 系统弹窗
                        ├─ 允许 → 执行功能
                        ├─ 拒绝 → 功能降级
                        └─ 拒绝且不再询问 → 引导到系统设置
```

---

### 用 Activity Result API 申请

```kotlin
class MainActivity : ComponentActivity() {

    private val cameraPermission = registerForActivityResult(
        ActivityResultContracts.RequestPermission()
    ) { granted ->
        if (granted) openCamera() else showRationale()
    }

    private fun checkAndRequest() {
        when {
            ContextCompat.checkSelfPermission(this, Manifest.permission.CAMERA)
                    == PackageManager.PERMISSION_GRANTED -> openCamera()

            shouldShowRequestPermissionRationale(Manifest.permission.CAMERA) ->
                showRationaleDialog { cameraPermission.launch(Manifest.permission.CAMERA) }

            else -> cameraPermission.launch(Manifest.permission.CAMERA)
        }
    }
}
```

---

### 在 Compose 中申请

```kotlin
@Composable
fun CameraButton(onGranted: () -> Unit) {
    val context = LocalContext.current
    var showSettings by remember { mutableStateOf(false) }

    val launcher = rememberLauncherForActivityResult(
        ActivityResultContracts.RequestPermission()
    ) { granted ->
        if (granted) onGranted() else showSettings = true
    }

    Button(onClick = {
        val granted = ContextCompat.checkSelfPermission(
            context, Manifest.permission.CAMERA
        ) == PackageManager.PERMISSION_GRANTED
        if (granted) onGranted() else launcher.launch(Manifest.permission.CAMERA)
    }) { Text("拍照") }

    if (showSettings) SettingsDialog { showSettings = false }
}
```

---

### 申请多个权限

```kotlin
val multiLauncher = rememberLauncherForActivityResult(
```

### 跳转到系统设置

```kotlin
fun openAppSettings(context: Context) {
    val intent = Intent(
        Settings.ACTION_APPLICATION_DETAILS_SETTINGS,
        Uri.fromParts("package", context.packageName, null)
    )
    context.startActivity(intent)
}
```

> 当 `shouldShowRequestPermissionRationale` 返回 `false` 且未授权，说明用户选择了"不再询问"，此时**再申请不会弹窗**，只能引导到设置页。

### 调用系统相机（无需权限）

```kotlin
var imageUri by remember { mutableStateOf<Uri?>(null) }

val takePicture = rememberLauncherForActivityResult(
    ActivityResultContracts.TakePicture()
) { success -> if (!success) imageUri = null }

Button(onClick = {
    imageUri = createImageUri(context)      // 通过 FileProvider 创建
    imageUri?.let { takePicture.launch(it) }
}) { Text("拍照") }

imageUri?.let {
    AsyncImage(model = it, contentDescription = null, modifier = Modifier.size(200.dp))
}
```

> 用 `ACTION_IMAGE_CAPTURE` 调用系统相机**不需要** `CAMERA` 权限；只有自建相机预览才需要。

---

### FileProvider 配置

```xml
<!-- AndroidManifest.xml -->
<provider
    android:name="androidx.core.content.FileProvider"
    android:authorities="${applicationId}.fileprovider"
    android:exported="false"
    android:grantUriPermissions="true">
    <meta-data android:name="android.support.FILE_PROVIDER_PATHS"
               android:resource="@xml/file_paths" />
</provider>
```

```xml
<!-- res/xml/file_paths.xml -->
<paths>
    <external-files-path name="images" path="Pictures/" />
    <cache-path name="cache" path="." />
</paths>
```

> Android 7.0 起禁止直接传递 `file://` URI，必须用 `FileProvider` 生成 `content://`。

### 读取与保存图片

```kotlin
// 读取 Uri 内容
suspend fun readImage(context: Context, uri: Uri): ByteArray? =
    withContext(Dispatchers.IO) {
        context.contentResolver.openInputStream(uri)?.use { it.readBytes() }
    }

// 保存到相册（MediaStore，无需权限）
suspend fun saveToGallery(context: Context, bitmap: Bitmap, name: String) =
    withContext(Dispatchers.IO) {
        val values = ContentValues().apply {
            put(MediaStore.Images.Media.DISPLAY_NAME, name)
            put(MediaStore.Images.Media.MIME_TYPE, "image/jpeg")
            put(MediaStore.Images.Media.RELATIVE_PATH, Environment.DIRECTORY_PICTURES)
        }
        val uri = context.contentResolver.insert(
            MediaStore.Images.Media.EXTERNAL_CONTENT_URI, values
        )
        uri?.let {
            context.contentResolver.openOutputStream(it)?.use { out ->
                bitmap.compress(Bitmap.CompressFormat.JPEG, 90, out)
            }
        }
    }
```

### 获取位置

```kotlin
implementation("com.google.android.gms:play-services-location:21.3.0")
```

```kotlin
@SuppressLint("MissingPermission")     // 调用前必须已检查权限
suspend fun getCurrentLocation(context: Context): Location? {
    val client = LocationServices.getFusedLocationProviderClient(context)
    return client.getCurrentLocation(
        Priority.PRIORITY_HIGH_ACCURACY,
        CancellationTokenSource().token
    ).await()
}
```

- 国内设备可用系统 `LocationManager` 或第三方 SDK（高德、百度）
- 精确定位 `ACCESS_FINE_LOCATION` / 模糊定位 `ACCESS_COARSE_LOCATION`
- Android 12+ 用户可选择"仅授予大致位置"

### 传感器

```kotlin
class StepCounter(context: Context) : SensorEventListener {
    private val sensorManager = context.getSystemService(SensorManager::class.java)
    private val sensor = sensorManager.getDefaultSensor(Sensor.TYPE_ACCELEROMETER)

    fun start() = sensorManager.registerListener(
        this, sensor, SensorManager.SENSOR_DELAY_NORMAL
    )
    fun stop() = sensorManager.unregisterListener(this)

    override fun onSensorChanged(event: SensorEvent) {
        val (x, y, z) = event.values
    }
    override fun onAccuracyChanged(sensor: Sensor?, accuracy: Int) {}
}
```

> 传感器**必须在 `onPause`/`onStop` 注销**，否则持续耗电。

---

### 在 Compose 中封装传感器

```kotlin
@Composable
fun rememberAccelerometer(): State<Triple<Float, Float, Float>> {
    val context = LocalContext.current
    val state = remember { mutableStateOf(Triple(0f, 0f, 0f)) }

    DisposableEffect(Unit) {
        val manager = context.getSystemService(SensorManager::class.java)
        val listener = object : SensorEventListener {
            override fun onSensorChanged(e: SensorEvent) {
                state.value = Triple(e.values[0], e.values[1], e.values[2])
            }
            override fun onAccuracyChanged(s: Sensor?, a: Int) {}
        }
        manager.registerListener(
            listener,
            manager.getDefaultSensor(Sensor.TYPE_ACCELEROMETER),
            SensorManager.SENSOR_DELAY_UI
        )
        onDispose { manager.unregisterListener(listener) }
    }
    return state
}
```

### 通知渠道（Android 8.0+ 必需）

```kotlin
fun createChannel(context: Context) {
    val channel = NotificationChannel(
        "reminder",                                  // 渠道 ID
        "任务提醒",                                    // 用户可见的名称
        NotificationManager.IMPORTANCE_DEFAULT
    ).apply {
        description = "待办任务到期提醒"
        enableVibration(true)
    }
    context.getSystemService(NotificationManager::class.java)
        .createNotificationChannel(channel)
}
```

> 渠道的重要性、声音、震动一旦创建**只能由用户修改**，应用无法再改。渠道要在 `Application.onCreate` 中创建。

---

### 发送通知

```kotlin
fun showNotification(context: Context, title: String, content: String) {
    val intent = Intent(context, MainActivity::class.java).apply {
        flags = Intent.FLAG_ACTIVITY_NEW_TASK or Intent.FLAG_ACTIVITY_CLEAR_TASK
        putExtra("from_notification", true)
    }
    val pending = PendingIntent.getActivity(
        context, 0, intent,
        PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_IMMUTABLE
    )

    val notification = NotificationCompat.Builder(context, "reminder")
        .setSmallIcon(R.drawable.ic_notification)
        .setContentTitle(title)
        .setContentText(content)
        .setStyle(NotificationCompat.BigTextStyle().bigText(content))
        .setPriority(NotificationCompat.PRIORITY_DEFAULT)
        .setContentIntent(pending)
        .setAutoCancel(true)
        .build()

    NotificationManagerCompat.from(context).notify(1001, notification)
}
```

---

### 通知权限（Android 13+）

```xml
<uses-permission android:name="android.permission.POST_NOTIFICATIONS" />
```

```kotlin
val notificationPermission = rememberLauncherForActivityResult(
```

## 第六节 后台任务与 WorkManager

- 后台执行限制
- WorkManager
- 约束与周期任务

---

### 后台执行限制

Android 对后台的限制逐版本收紧：

| 版本 | 限制 |
| --- | --- |
| 6.0 | Doze 与 App Standby |
| 8.0 | 后台 Service 限制、隐式广播限制 |
| 10 | 限制后台启动 Activity |
| 12 | 禁止从后台启动前台服务（部分情况） |
| 13+ | 通知需授权、前台服务类型必须声明 |

> 结论：**延迟、周期、可靠的后台任务一律用 `WorkManager`**，不要自己起 Service 或 AlarmManager。

---

### WorkManager 基础

```kotlin
implementation("androidx.work:work-runtime-ktx:2.9.1")
```

```kotlin
class SyncWorker(
    context: Context,
    params: WorkerParameters
) : CoroutineWorker(context, params) {

    override suspend fun doWork(): Result = try {
        val repository = (applicationContext as MyApplication).container.newsRepository
        repository.refresh()
        Result.success()
    } catch (e: IOException) {
        Result.retry()                  // 稍后自动重试
    } catch (e: Exception) {
        Result.failure()
    }
}
```

---

### 提交任务

```kotlin
// 一次性任务
val request = OneTimeWorkRequestBuilder<SyncWorker>()
    .setConstraints(
        Constraints.Builder()
            .setRequiredNetworkType(NetworkType.CONNECTED)
            .setRequiresBatteryNotLow(true)
            .build()
    )
    .setBackoffCriteria(BackoffPolicy.EXPONENTIAL, 30, TimeUnit.SECONDS)
    .setInputData(workDataOf("type" to "manual"))
    .build()

WorkManager.getInstance(context).enqueue(request)

// 周期任务（最小间隔 15 分钟）
val periodic = PeriodicWorkRequestBuilder<SyncWorker>(6, TimeUnit.HOURS).build()
WorkManager.getInstance(context).enqueueUniquePeriodicWork(
    "sync", ExistingPeriodicWorkPolicy.KEEP, periodic
)
```

---

### 观察任务状态

```kotlin
@Composable
fun SyncStatus(context: Context) {
    val workInfos by WorkManager.getInstance(context)
        .getWorkInfosForUniqueWorkLiveData("sync")
        .observeAsState(emptyList())

    val state = workInfos.firstOrNull()?.state
    when (state) {
        WorkInfo.State.RUNNING -> Text("同步中...")
        WorkInfo.State.SUCCEEDED -> Text("同步完成")
        WorkInfo.State.FAILED -> Text("同步失败")
        else -> Unit
    }
}
```

WorkManager 的保证：**任务被持久化到数据库，应用退出甚至设备重启后仍会执行**。

### 前台服务

```xml
<uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE_MEDIA_PLAYBACK" />

<service android:name=".MusicService"
```

```kotlin
class MusicService : Service() {
    override fun onStartCommand(intent: Intent?, flags: Int, startId: Int): Int {
        startForeground(1, buildNotification())   // 必须在 5 秒内调用

    }
}
```

> 仅用于**用户可感知**的持续任务：音乐播放、导航、健身记录、通话。

## 本章小结

- 权限分普通/危险/特殊；危险权限必须**运行时**申请，并处理"不再询问"
- 能不申请权限就不申请：系统相机 Intent、Photo Picker、MediaStore 都无需权限
- Android 7.0+ 传文件必须用 `FileProvider`；`PendingIntent` 必须指定可变性标志
- 传感器与广播"注册必注销"，否则耗电与泄漏
- 后台任务用 **WorkManager**；前台服务仅限用户可感知的持续任务
